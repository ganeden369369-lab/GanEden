**Device testing note (2026-08-28):** the App Store build of Expo Go is stuck on SDK 54 (Apple approval backlog; Expo changelog "Expo Go and the App Store in May 2026" and the SDK 57 post), so the SDK 57 app cannot run in Expo Go on iPhone. Decision: Phase 1–4 are verified on Expo Web + code review; the first on-device pass happens when an Apple Developer membership exists — then use an **EAS development build** (not Expo Go), which Phase 5 needs anyway for RevenueCat and Instagram Stories. Android phones can run Expo Go SDK 57 via the Expo CLI today if one is available. Until then, treat native-only behaviour (fonts, RTL row mirroring, date spinner, tab bar) as unverified.
